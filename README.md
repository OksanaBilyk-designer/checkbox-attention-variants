# Checkbox attention variants

An interactive prototype exploring animation variants that draw attention to a
"review agreement" checkbox on a mobile screen.

## Run it

Open `index.html` in any browser, or view the live version on GitHub Pages.

### Variants
- **Bounce** — checkbox hops up and down
- **Pulse ring** — soft blue halo ripples out
- **Nudge** — the row shakes sideways once
- **Row highlight** — the row flashes a blue tint
- **Pop and glow** — checkbox springs larger, then glows
- **Hint tooltip** — helper text appears above the checkbox
